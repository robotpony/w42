Your projects already live in plain text. Space Command reads them and shows you the one thing to do next.

**Space Command** (␣⌘) is a native macOS sidebar app. It reads the projects you already keep, like Git repos, notes, and Hugo blogs, without asking you to move them into another tool. It sits beside your work and answers one question: *what's next?*

The tool started as an Obsidian plugin, both as a way to cut my teeth on scratching an itch with Claude and as something I've wanted to build for a very long time. Obsidian is great, but I started wanting the features closer to the rest of my tools, so I re-imagined it as a macOS app.

## Where it's at

Space Command is in design right now. I'm working out what it reads, how it decides what "next" means, and how little sidebar it can get away with.
